# OneFellowship

> **Tagline:** Together We Stand  
> **Brand Colors:** Primary `#0B4FBB` | Dark `#0A2D6B` | Secondary `#FFC107` | Sky Blue `#29B6F6`

OneFellowship is an all-in-one community and fellowship management platform featuring a rich Single Page Web Application (PWA) and a native Flutter Android & iOS mobile app powered by Firebase.

## Features
- **Member Management:** Member registration, directory, role management (admin/member), profile updates.
- **Virtual Membership Cards:** Real-time generation of custom OneFellowship virtual cards with member photo, ID, QR code, and export to image/PDF.
- **Contributions & Payments:** Track fellowship contributions, welfare dues, monthly dues, and view payment histories.
- **Firebase Backend:** Firebase Authentication and Cloud Firestore for real-time security and sync.
- **PWA & Mobile Native App:** PWA web app + native Flutter Android app (`org.onefellowship.app`).

## Setup & Running
- **Web App:** Open `index.html` or serve with any static web server.
- **Android App:** Located in `flutter_app/`. Run `flutter run` or `flutter build apk --release`.
